# Hosts IP Checker

Все сделано на основе вайбкодинга. Небольшая программа, которая проверяет, какие IP-адреса из вашего списка сейчас работают для записи в файл `hosts`. Проверяет домены Spotify, ChatGPT, Claude и Google Gemini и показывает лучший IP для каждого сервиса.

## Зачем это нужно

Если для доступа к сервисам вы вручную прописываете IP-адреса в `hosts`, адрес может в любой момент перестать работать. Проверять каждый адрес вручную долго. Программа делает это автоматически и в конце выдаёт готовые строки для `hosts`.

## Как это работает

Для каждого IP и каждого домена программа:

1. подключается к IP по порту 443;
2. выполняет TLS-рукопожатие с нужным доменом (SNI) и проверяет сертификат;
3. отправляет HTTP-запрос с заголовком `Host`.

Любой HTTP-ответ (200, 301, 403, 404 и т. д.) означает, что домен через этот IP доступен.

Во время работы выводится результат по каждому IP и общий прогресс:

```
[12/50] 203.0.113.5
    Spotify             ... OK   19/19
    ChatGPT (OpenAI) AI ... PART 20/30
    Claude AI           ... FAIL 0/26
    Google Gemini AI    ... OK   63/63
```

`OK` - работают все домены сервиса, `PART` - часть доменов, `FAIL` - ни один.

В конце для каждого сервиса показывается лучший IP, а строки для `hosts` сохраняются в `hosts_result.txt`. В файл попадают только домены, которые реально ответили.

## Файлы

| Файл | Назначение |
|------|-----------|
| `check_ips.py` | сама программа |
| `domens.txt` | домены, разбитые на разделы вида `# Spotify` |
| `geohide_ip_address.txt` | список IP-адресов для проверки (по одному в строке, `#` - комментарий) |
| `build_exe.bat` | сборка `.exe` для Windows |
| `hosts_result.txt` | результат работы, создаётся автоматически |

## Можно редактировать самостоятельно

Можете вписать в domens.txt свои домены и в geohide_ip_address.txt свои IP-адреса. Программа так же прогонит все адреса через домены и даст результат.

## Запуск

Нужен Python 3.9 или новее, сторонние библиотеки не требуются.

```
python check_ips.py                      # все сервисы
python check_ips.py --section Spotify    # только один сервис
python check_ips.py --timeout 8 --workers 30
```

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `--section` | сервис (часть названия раздела в `domens.txt`) или `all` | `all` |
| `--timeout` | таймаут подключения, секунды | `5` |
| `--workers` | сколько IP проверять одновременно | `15` |
| `--no-verify` | не проверять сертификат | выключено |

## Сборка `.exe` (Windows)

Чтобы запускать программу без установленного Python, запустите `build_exe.bat`. Он установит PyInstaller и соберёт `dist\SpotifyIPCheck.exe`. Положите `.exe` в одну папку с `domens.txt` и `geohide_ip_address.txt`.

Антивирусы иногда ложно срабатывают на файлы, собранные PyInstaller. Если это произошло, добавьте файл в исключения или запускайте скрипт через Python.

## Ограничения

- Программа проверяет только доступность домена через IP, но не меняет файл `hosts` сама.
- Часть технических доменов (например, `o.pki.goog`) может не отвечать даже через рабочий IP.
- Работает только с IPv4-адресами.
